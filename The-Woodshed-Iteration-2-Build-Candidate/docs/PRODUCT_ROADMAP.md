# Product Roadmap

## Implemented beta primitives
- League DNA correctness remediation and draft-type segmentation.
- Scoring-aware ROS ranking primitive with enforced horizon/data-quality metadata.
- Trade, waiver, Start/Sit and Guillotine decision engines with improved league/roster constraints.
- Deterministic evidence-linked player insight; optional gated AI summarization.
- Normalized canonical schemas, Sleeper league normalization and persistence foundation.
- Structured Woodshed workbench UI instead of raw JSON.

## Required before a credible public-beta READY verdict
1. Resolve frontend registry/lockfile and complete build/E2E/a11y verification.
2. Execute DB migrations/integration, Docker/Compose, security scans and staging drills.
3. Wire authorized projection, market value, historical ADP and availability sources.
4. Preload every tool from the user's synced league/player pool rather than requiring analytical values manually.
5. Complete whole-lineup Start/Sit optimization and roster-aware replacement/scarcity derivation.
6. Backtest/calibrate analytical claims on chronological held-out datasets and publish results in model cards.
7. Add full account/session/object authorization before persistent multi-user features.
